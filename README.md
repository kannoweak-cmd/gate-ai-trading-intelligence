# Gate AI Trading Intelligence

Dashboard edukasi untuk memantau data pasar publik Gate.io.

## Menjalankan
1. Install dependensi: `pip install -r requirements.txt`
2. Jalankan: `streamlit run app.py`

## Deploy gratis
Unggah `app.py`, `requirements.txt`, dan `README.md` ke repository GitHub.
Lalu hubungkan repository ke Streamlit Community Cloud.

Aplikasi hanya membaca endpoint publik Gate.io. Tidak memerlukan API key dan tidak mengirim order.
